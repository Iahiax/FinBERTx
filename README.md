# FinBERTx — تحليل أخبار الفوركس على CPU

مشروع Python لتحليل الأخبار المالية باستخدام `ProsusAI/finbert`، ومراقبة مفكرة اقتصادية، وإرسال النتائج إلى Telegram. يكتشف أزواج الفوركس المتاحة في Capital.com. لا ينفذ المشروع معاملات مالية: عميل Capital.com للقراءة فقط على نقطة Demo لاكتشاف الأسواق والأسعار التاريخية، وكل الإشارات محاكاة افتراضية. لا يوجد عنوان API حي أو خيار لتغيير الرافعة.

> عقود الفروقات عالية المخاطر وقد تؤدي إلى خسائر كبيرة. هذا المشروع ليس نصيحة استثمارية ولا يضمن أداءً. ابدأ بالتحليل دون أوامر، ثم اختبر في حساب Demo فقط. لا ترفع حد الحجم أو الرافعة؛ الكود يفرض سقوفًا منخفضة.

## ما الذي يفعله؟

- تحميل FinBERT محليًا على **CPU فقط** باستخدام `torch.device("cpu")`، ثم إخراج درجات Positive / Negative / Neutral.
- قراءة عناوين أخبار الفوركس ومواعيد الاقتصاد من Finnhub، مع دعم اختياري لمفكرة FMP وتواريخ إصدارات FRED.
- استخدام قائمة أزواج العملات التي ترجعها Capital.com وتصفيتها إلى أسواق الفوركس.
- تجاهل الإشارة إذا لم يحدد الخبر عملة واحدة بوضوح، أو كانت المشاعر ضعيفة، أو كان السوق غير قابل للتداول.
- إيقاف إرسال الإشارات قبل/بعد الأحداث الاقتصادية عالية التأثير على إحدى عملتي الزوج.
- التشغيل للتحليل والتنبيه والمحاكاة فقط. `ENABLE_DEMO_ORDERS=true` مرفوض صراحةً ولا توجد نقطة كتابة للأوامر.
- أوامر Telegram: `/status` و`/pause` و`/resume` و`/backtest` و`/signals` و`/help`.
- تقرير اختبار تاريخي دوري عند ضبط ملف CSV صالح. لا ينشئ البوت نتائج أو أرباحًا افتراضية عند غياب البيانات.
- سجل محلي SQLite لمنع تحليل الخبر نفسه مرتين وحفظ حالة الإيقاف والأحداث.

### قيود التداول المقصودة

- Capital.com **Demo للقراءة فقط**؛ عنوان الخادم التجريبي ثابت داخل الكود. قيمة `CAPITAL_ENV` غير `demo` مرفوضة.
- `ENABLE_DEMO_ORDERS=false` افتراضيًا، ولا يتم تعديل إعداد الرافعة في حساب الوسيط.
- لا توجد أوامر أو حجم أو رافعة يمكن إرسالها من المشروع. حدود المحاكاة لا تمثل حماية من خسارة فعلية.
- لا تستخدم بيانات الخبر وحدها لفتح صفقة إذا تعذر تحديث المفكرة الاقتصادية.
- نقاط الأسعار تُؤخذ من قواعد السوق الحالية؛ إذا رفض الوسيط الحجم أو المسافة أو الأمر، لا يعيد البوت إرسال أمر فتح غير مؤكد.
- واجهة Capital.com لا تضمّن «فريمًا» في أمر فتح الصفقة؛ تُستخدم الفريمات في بيانات الأسعار والاختبارات التاريخية. الفريمات التي يدعمها عميل البيانات: `MINUTE`, `MINUTE_5`, `MINUTE_15`, `MINUTE_30`, `HOUR`, `HOUR_4`, `DAY`, `WEEK`.
- FinBERT الأصلي نموذج إنجليزي. تحليل عناوين عربية مباشرةً غير مدعوم جيدًا؛ استخدم أخبارًا إنجليزية أو نموذجًا مرخصًا ومدربًا للعربية.

## التثبيت والتشغيل على Linux VPS

يتطلب Python 3.11 أو 3.12 واتصال إنترنت لتنزيل أوزان النموذج أول مرة. `requirements.txt` يختار إصدار PyTorch الخاص بـ CPU، كما يفرض كود الاستدلال `torch.device("cpu")` وينقل النموذج والمدخلات إلى CPU.

```bash
git clone https://github.com/Iahiax/FinBERTx.git
cd FinBERTx
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
cp .env.example .env
chmod 600 .env
```

أدخل مفاتيح **جديدة بعد إلغاء المفاتيح التي ظهرت في المحادثة** داخل `.env` على VPS فقط. لا ترسلها في المحادثة ولا ترفع `.env` إلى GitHub. احفظ مفاتيح Capital.com التي تستخدمها هنا لحساب Demo، وليس لحساب حقيقي.

ابدأ بوضع التحليل فقط:

```bash
python -m finbertx check-config
python -m finbertx analyze "The central bank held rates steady as inflation eased."
python -m finbertx run
```

لجلب بيانات Demo للقراءة فقط، أضف مفاتيح حساب Demo الجديدة في `.env` مع إبقاء `ENABLE_DEMO_ORDERS=false`. لا يوجد دعم للتداول الحقيقي أو إرسال أوامر أو رفع الرافعة.

لتشغيل المراقبة غير التداولية على VPS، استخدم `deploy/finbertx.service` عبر systemd، مع ملف بيئة لا يقرأه سوى مستخدم الخدمة. أوقف الخدمة فورًا إذا لم تعد ترغب في تشغيلها.

## مفاتيح البيئة

| المتغير | الاستخدام |
| --- | --- |
| `FINNHUB_API_KEY` | أخبار الفوركس والمفكرة الاقتصادية |
| `FMP_API_KEY` | مصدر اختياري للمفكرة الاقتصادية |
| `FRED_API_KEY` | تواريخ الإصدارات الاقتصادية الأمريكية |
| `CAPITAL_API_KEY` / `CAPITAL_IDENTIFIER` / `CAPITAL_PASSWORD` | دخول API لحساب Capital.com التجريبي |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | إرسال التنبيهات إلى المجموعة أو القناة |
| `TELEGRAM_ALLOWED_CHAT_IDS` | قائمة مفصولة بفواصل لمعرّفات من يُسمح لهم بإرسال أوامر التحكم |
| `ENABLE_DEMO_ORDERS` | يجب أن يبقى `false`; القيمة `true` مرفوضة |
| `BACKTEST_CSV` | مسار ملف بيانات الاختبار التاريخي |

استخدم `.env.example` لبقية الحدود. لا تضع أي قيمة سرية في الشيفرة أو في مستودع عام.

## الاختبار التاريخي

أعمدة CSV المطلوبة:

```text
timestamp,epic,direction,entry_price,exit_price
2026-01-01T00:00:00Z,EURUSD,BUY,1.1000,1.1050
```

`direction` إما `BUY` أو `SELL`. النتائج نسبية، ولا تشمل فروق الأسعار أو الرسوم أو التمويل الليلي ما لم تكن هذه التكاليف ممثلة في أسعار الإدخال. للتحليل:

```bash
python -m finbertx backtest --csv data/backtest.csv
```

لإرسال تقرير دوري إلى Telegram، اضبط `BACKTEST_CSV` و`BACKTEST_REPORT_INTERVAL_HOURS`. يجب توفير بيانات تاريخية صالحة بنفسك؛ هذا المشروع لا يدّعي اختبار استراتيجية على بيانات لم تُحمّل.
