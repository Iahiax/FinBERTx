# FinBERTx — تحليل أخبار ومحاكاة ورقية

مشروع Python لتحليل الأخبار المالية الإنجليزية باستخدام `ProsusAI/finbert` على CPU، ومراقبة الأسواق المتاحة في Capital.com. يبدأ التشغيل في وضع Paper المحلي؛ لا تُرسل أوامر للوسيط إلا بعد اجتياز بوابات Demo أو Live الصريحة. هذا المشروع ليس نصيحة استثمارية، وعقود الفروقات والرافعة قد تسبب خسائر كبيرة.

## ما يفعله الآن

- يجلب أخبار Finnhub من فئتي `general` و`forex`، ويطابق رموز الأدوات وأسماءها مع الخبر. المطابقة تقريبية وقد لا تكشف كل أداة متأثرة.
- يدعم تقويم الأحداث الاقتصادية من Finnhub وFMP وFRED عند توفير مفاتيحها؛ تُستخدم الأحداث عالية الأثر المعروفة لتطبيق فترات الحظر.
- يقرأ قائمة الأسواق والأسعار وبيانات OHLC من Capital.com عند إعداد بيانات Demo. يدعم بث الأسعار والأطر `MINUTE`, `MINUTE_5`, `MINUTE_15`, `MINUTE_30`, `HOUR`, `HOUR_4`, `DAY`, `WEEK`؛ حد البث 40 أداة في الوقت نفسه، لذلك يدوّر الاشتراكات عند زيادة الأسواق.
- يرصد توافق SMA 5/20 عبر الأطر بوصفه ملاحظة سعرية مستقلة، وليس إشارة FinBERT.
- يوفّر `/backtest <EPIC>` اختبارًا سعريًا متعدد الأطر ويعيد **تقريرًا نصيًا** في محادثة Telegram. يجلب شموع OHLC على صفحات لا تتجاوز 1,000 شمعة لكل طلب وحتى 100 صفحة لكل إطار. يوضح التقرير عدد الشموع والمدى والصفقات والنتائج والتراجع، ولا يختلق أرقامًا عند غياب البيانات.

### ما لا يفعله الباكتيست الحالي

`/backtest <EPIC>` يختبر تقاطع SMA 5/20 على الأسعار، وليس FinBERT. لا تتوفر هنا مجموعة تاريخية موثقة تربط نص الخبر ووقت نشره الفعلي بدرجات النموذج وسعر الأداة وتكاليف التداول عند اللحظة نفسها. كما أن التقرير لا يحاكي حد الخسارة اليومية الورقي ولا يحتسب التمويل الليلي والعمولات والانزلاق بالكامل، ولا يثبت ربحية مستقبلية. [تصميم جمع البيانات اللازمة لباكتيست مشاعر متزامن (غير منفذ بعد)](docs/historical-sentiment-backtest.md).

## حدود المخاطر وسلامة التشغيل

- `PAPER_MAX_LEVERAGE=100` سقف صلب **وليس هدفًا**؛ لا يمكن ضبطه فوق 100:1. حجم الصفقة يخضع أيضًا للمخاطرة والوقف وحد التعرض، لذا قد تكون الرافعة الفعلية أقل كثيرًا.
- `MAX_EPIC_EXPOSURE_FRACTION=0.25` يحد القيمة الاسمية لكل أداة إلى 25% من الرصيد افتراضيًا. يُطبّق على مراكز Paper وحجم أوامر الوسيط، إضافة إلى منع فتح مركز آخر على الأداة نفسها عند وجود مركز قائم. يمكن ضبط النسبة بين 1% و100%؛ ابدأ بالقيم الصغيرة.
- `PAPER_DAILY_LOSS_LIMIT_FRACTION=0.03` يوقف فتح مراكز Paper جديدة بعد بلوغ خسارة 3% من حقوق بداية يوم UTC المحفوظة في SQLite. يراعي دفتر Paper وأسعار المراكز المفتوحة المتاحة لحظة الفحص، لكنه لا يغلق المراكز المفتوحة. إذا بدأ البرنامج متابعة اليوم متأخرًا، فإن خط البداية هو أول حقوق مرصودة لذلك اليوم.
- **حد الخسارة اليومي يخص Paper فقط.** لا نطبقه على Demo/Live لأن الرصيد المتاح من الوسيط لا يكفي هنا لاحتساب خسارة اليوم العائمة، والتداول اليدوي أو خارج البرنامج غير ممثل في دفتره. لا تعتمد على حد Paper لحماية حساب الوسيط.
- الإعداد المبدئي `MAX_OPEN_POSITIONS=1` و`MAX_DAILY_DEMO_ORDERS=1` للتدرج المحافظ؛ اسم متغير الحد اليومي تاريخي ويطبق على محاولات كل أوضاع الوسيط. يُنصح بمرحلة Demo طويلة وقراءة فقط أولًا، ثم اختبار أداة واحدة وحدود صغيرة، ومراجعة النتائج يدويًا قبل أي انتقال.
- يستخدم Demo وLive مجموعة Capital.com نفسها (`CAPITAL_API_KEY`, `CAPITAL_IDENTIFIER`, `CAPITAL_PASSWORD`)، ويختار البرنامج مضيف API بحسب الوضع المختار. تبقى أوامر Demo مقفلة افتراضيًا وتتطلب `ENABLE_DEMO_ORDERS=true` ثم اختيار `/mode demo` صراحةً من محادثة Telegram خاصة مسموح بها. إعدادات Live معطلة افتراضيًا (`LIVE_TRADING_ENABLED=false`)؛ ويتطلب Live بواباته المستقلة ومحادثة خاصة ضمن القائمة، ثم `/mode live` وتأكيدًا ثانيًا مؤقتًا من المحادثة نفسها. لا يبقى Live مفعّلًا بعد إعادة التشغيل.
- أوامر التحكم لا تُقبل إلا من محادثة Telegram خاصة ومعرّف موجود في `TELEGRAM_ALLOWED_CHAT_IDS`. لا تستخدم مجموعة للتحكم. لا تضع أي بيانات اعتماد في Git أو في `.env.example`؛ خزّن القيم الجديدة في `.env` بصلاحية `600`، ولا تشاركها في المحادثات.

## التثبيت والتشغيل

يتطلب Python 3.11 أو 3.12 واتصال إنترنت لتنزيل أوزان FinBERT أول مرة.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
cp .env.example .env
chmod 600 .env
```

أدخل مفاتيح جديدة فقط في `.env` عند الحاجة. ابدأ بتحليل نص أو Paper، ولا تملأ بيانات Live لتجربة المشروع.

```bash
python -m finbertx check-config
python -m finbertx analyze "The central bank held rates steady as inflation eased."
python -m finbertx run
```

راجع [دليل VPS](deploy/README.md) قبل التشغيل كخدمة.

## أوامر Telegram

الأوامر المنفذة في الشيفرة:

| الأمر | الوظيفة |
| --- | --- |
| `/start` و`/help` | المساعدة. |
| `/analyze <text>` | تحليل نص مالي وإظهار احتمالات Positive/Negative/Neutral. |
| `/status` | حالة التشغيل وملخص Paper والأسواق المتاحة. |
| `/pause` و`/resume` | إيقاف/استئناف فتح مراكز جديدة؛ الإيقاف لا يغلق المراكز القائمة. |
| `/backtest <EPIC>` | تقرير أسعار تاريخي نصي متعدد الأطر. مثال: `/backtest EURUSD`. |
| `/backtest` | يعرض تعليمات الاستخدام؛ يلزم رمز EPIC. لا يرسل CSV إلى Telegram. |
| `/signals` و`/risk` | ملخص الإشارات وحدود المخاطر. |
| `/mode` | عرض الوضع؛ `/mode paper` و`/mode demo` للتغيير، و`/mode live` مع تأكيد ثانٍ عند اجتياز بوابات Live. |

لإظهار القائمة في `@BotFather` عبر `/setcommands`، أدخل أسماء الأوامر بلا `/`:

```text
start - عرض المساعدة
help - عرض الأوامر والمساعدة
analyze - تحليل نص مالي
status - عرض حالة التشغيل
pause - إيقاف فتح مراكز جديدة
resume - استئناف فتح مراكز جديدة
backtest - تقرير أسعار متعدد الأطر؛ أرفق EPIC
signals - عرض ملخص الإشارات
risk - عرض حدود المخاطرة
mode - عرض أو تغيير وضع التشغيل
```

## CSV محلي عبر CLI فقط

يمكن الاحتفاظ بمسار CSV كمدخل محلي لأمر CLI؛ لا يستخدمه البوت ولا يرسله إلى Telegram. الأعمدة المطلوبة:

```text
timestamp,epic,direction,entry_price,exit_price
2026-01-01T00:00:00Z,EURUSD,BUY,1.1000,1.1050
```

```bash
python -m finbertx backtest --csv data/backtest.csv --starting-balance 10000 --leverage 100
```

لا ينشئ هذا المسار بيانات بديلة، ولا يطبق جميع تكاليف التداول أو نموذج تصفية الهامش.

## الاختبارات والحدود

```bash
python -m compileall -q finbertx tests
python -m unittest discover -s tests -v
git diff --check
```

الاختبارات تستخدم Fixtures ومحاكاة محلية ولا تتصل بـCapital.com أو Telegram ولا تحتاج مفاتيح. لم تُختبر جلسة Capital.com أو البث الحقيقي أو إرسال أوامر Demo/Live.

راجع [Capital.com Open API](https://open-api.capital.com/)، [Finnhub Market News](https://finnhub.io/docs/api/market-news)، و[بطاقة FinBERT وترخيصه](https://huggingface.co/ProsusAI/finbert). ترخيص أوزان FinBERT هو `CC BY-NC-SA 4.0`؛ راجع القيود قبل أي استخدام تجاري.
