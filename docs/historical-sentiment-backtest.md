# تصميم باكتيست مشاعر تاريخي متزامن — غير منفذ بعد

هذا مستند تصميم فقط. لا يحفظ التطبيق حاليًا أرشيفًا تاريخيًا للأخبار ودرجات FinBERT وتكاليف التداول، ولا ينفذ باكتيستًا متزامنًا لمشاعر الأخبار. أمر Telegram `/backtest <EPIC>` ما يزال باكتيستًا سعريًا لـSMA 5/20، ولا ينبغي وصفه بأنه اختبار FinBERT.

## البيانات المطلوبة

ينبغي تخزين سجلات ذات مصدر ووقت UTC واضحين، مع تمييز وقت الحدث عن وقت الاستلام:

| سجل مقترح | حقول أساسية |
| --- | --- |
| `news_observations` | `provider`, `news_id`, `published_at_utc`, `first_seen_at_utc`, `headline` أو مرجع مرخّص له، `related_symbols`, `content_hash` |
| `sentiment_results` | `news_id`, `model_name`, `model_revision`, `inference_at_utc`, درجات `positive/negative/neutral`, نسخة إعدادات المطابقة |
| `price_bars` | `epic`, `resolution`, `bar_start_utc`, `bar_end_utc`, bid/ask OHLC، مصدر البيانات، حالة اكتمال الشمعة |
| `cost_observations` | `epic`, `observed_at_utc`, spread، commission، financing/swap، قواعد الرسوم ومصدرها |
| `instrument_mapping` | رمز الخبر والأداة المرتبطة، قاعدة الربط، وقت صلاحية الربط ومصدره |

لا تخزن محتوى أخبار لا يجيز مزود البيانات حفظه أو إعادة استخدامه؛ عند تعذر التخزين، يلزم مصدر تاريخي مرخّص يعيد العناوين وقت نشرها.

## قواعد المحاذاة لمنع الانحياز

1. استخدم وقت النشر الأصلي للخبر، واحتفظ منفصلًا بوقت وصوله إلى البوت. لا تستخدم الخبر قبل وقت أول إتاحة موثوق.
2. أعد حساب FinBERT باستخدام نسخة نموذج ثابتة موثقة، أو سجّل الدرجات كما كانت متاحة وقتها؛ لا تستبدلها بدرجة حُسبت لاحقًا دون توضيح.
3. لا تدخل شمعة لم تكن قد أغلقت عند وقت القرار، ولا تستخدم أسعارًا مستقبلية لتحديد الأداة أو الاتجاه.
4. نفّذ الدخول على أول سعر bid/ask قابل للتداول بعد وقت القرار، مع قواعد واضحة للتأخير والمنطقة الزمنية والعطلات.
5. احتسب السبريد والعمولات والتمويل والانزلاق من بيانات مؤرخة ومصدرها معروف. إذا نقصت تكلفة أو شمعة، علّم العينة ناقصة ولا تخمّنها.
6. احتفظ بفترة تدريب/ضبط منفصلة عن فترة التقييم، وامنع تكرار الأخبار والمراجعات اللاحقة بين المجموعات.

## معايير قبل التنفيذ

قبل إضافة محرك الاختبار، يلزم تأكيد ترخيص حفظ الأخبار، تعريف قاعدة ربط الخبر بالأداة، توثيق مصادر التاريخ والتكاليف، وبناء اختبارات تثبت غياب التسرب الزمني. إلى ذلك الحين، لا يعرض المشروع نتائج أداء تاريخية لـFinBERT؛ اختباره متعدد الأطر الحالي خاص بالأسعار فقط.
